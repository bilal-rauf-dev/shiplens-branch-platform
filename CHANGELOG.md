# Changelog

All notable changes to ShipLens are documented here.
This file follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-02

### Added

- Project planning documents ([#1]).
- Django project, Docker setup, GitHub Actions, Render configuration and health probe ([#2]).
- Email authentication, role and branch permissions, and the audit foundation ([#5]).
- Branch register with generated codes and lifecycle transitions ([#6]).
- Volunteer applications and HR approval ([#7]).
- Member records and the audit log viewer, with handbook alignment ([#8]).
- Offline collections, the seven-day lock and transfers ([#9]).
- Weekly report submission, review and locking ([#10]).
- Dashboard, authored sample data, importer and operator demo rebuild ([#12]).
- Scoped CSV and PDF exports ([#14]).
- Public website and bilingual content manager ([#15]).
- Urdu localisation and right-to-left layouts ([#16]).
- Browser journeys, accessibility checks and the Lighthouse gate ([#22]).
- Architecture decisions, generated route reference and handover documentation ([#25]).

### Changed

- Material You design system adapted to handwritten CSS ([#11]).
- Illustrations, distinct icons, motion and staff layout refinements ([#27]).

### Fixed

- Material You visual details ([#13]).
- Findings from the project audit ([#17]).
- Heading font layout shifts and proxy header validation ([#24]).
- Missing weekly drafts at startup, branch-register counts and collection correction guidance ([#26]).

### Security

- Security hardening and performance improvements ([#21]).
